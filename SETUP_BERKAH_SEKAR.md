
# Setup Toko Berkah Sekar - 15jt Modal

## 1. Install APK
Download APK dari GitHub Actions.

## 2. Setting Awal (buka Pengaturan):
- Nama Toko: BERKAH SEKAR
- Modal Awal: 15000000
- Printer: Kosongkan dulu (mode preview aktif)

## 3. Mode Tanpa Printer (Sekarang):
- Setiap transaksi selesai -> muncul Preview Struk
- Tombol: [Share ke WhatsApp Pelanggan] [Simpan PDF] [Print Nanti]
- Lebih bayar / hutang tetap kecatat di menu Tagihan Hutang

## 4. Nanti Kalau Beli Printer Thermal 58mm Bluetooth:
- Nyalakan printer, pairing di HP (Settings > Bluetooth)
- Lihat MAC Address (contoh 66:22:AA:BB:CC:DD) di pengaturan Bluetooth HP
- Masukkan di aplikasi: Pengaturan > Alamat Printer Bluetooth
- Tes Print

Rekomendasi Printer Murah Surabaya:
- EPPOS RPP02N 58mm (Bluetooth) - 300rb
- Printer 58mm di Shopee/Tokopedia keyword "printer thermal bluetooth 58mm"

## 5. Laporan Laba:
- Modal Awal 15jt akan dipakai sebagai dasar perhitungan
- Laba = Total Jual - Total Modal Terjual
- Laporan harian otomatis reset jam 00:00

Semangat Berkah Sekar!
